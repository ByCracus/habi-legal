# Habi Legal

Public legal pages for the Habi app.

This repository hosts the static documents used for:

- Privacy Policy
- Terms of Service
- Account Deletion

- `https://bycracus.github.io/habi-legal/privacy-policy.html`
- `https://bycracus.github.io/habi-legal/terms-of-service.html`
- `https://bycracus.github.io/habi-legal/account-deletion.html`

the generated documents together after checking translation and content parity;
